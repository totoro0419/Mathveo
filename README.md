# Mathveo（マスヴェオ）

数学動画と参考書を融合した、新しい数学学習体験。

ライトテーマのReact / TypeScriptアプリです。初期版は**数学Ⅰ・二次関数の3テーマ**を実装しています。指定リポジトリ `totoro0419/Mathveo` を正本として開発しています。

## 起動

Node.js 22.12以降（CIは22）を使用してください。

```bash
npm ci
npm run dev
```

`http://localhost:4173/` を開きます。ローカルの別端末からはPCのLANアドレスと同じポートでアクセスできます。

```bash
npm run check
npm run build
npm run preview
```

`dist/` をHTTPSの静的ホストに配置できます。相対パスとハッシュルーティングを使うのでサブディレクトリでも動作します。プレビューと開発サーバーを同時に同じポートで起動しないでください。

## GitHub Pages

公開先は `https://totoro0419.github.io/Mathveo/` です。`.github/workflows/pages.yml` がmainの更新ごとに型・機能検査、ビルド、Pagesへのデプロイを行います。初回のみリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

公開の成否はGitHub Actionsの **Deploy Mathveo to GitHub Pages** と `github-pages` 環境のデプロイ結果で確認します。ワークフローの追加だけを公開成功とは扱いません。

アプリの数式・フォント・アイコン・Service Workerは相対パスで配信します。画面遷移は `#/library` などのハッシュ形式なので、教材の直リンクや再読み込みでもPagesの404を避けられます。別の公開URLで使っていた学習記録は、自動では移行されません。

## 初期版で使えるもの

- ホーム：続きから学習、科目への移動、最近の学習、実際の学習済み件数、復習待ち。
- ライブラリ：現行課程／公式サイト分類、教材の学習状態フィルタ、45単元の個別動画一覧（高校数学33・中学数学12）。
- 科目・単元の授業動画：公式サイトの45単元から取得した1,022本をVideo ID単位で登録。サムネイルのない単元別リストから各授業を選べます。表示タイトルは内容・授業／演習の区別を残して短く整え、元のタイトルは動画の詳細に保存しています。個別URL、前後の授業、単元内の動画一覧を利用できます。
- 動画視聴：公式YouTubeプレーヤーとMathveoの操作バー。再生・一時停止、10秒移動、シーク、再生速度・2倍速、音量・ミュート、全画面。PCの2ペイン、スマートフォンの縦並びと教材タブ。
- 数学教材：平方完成、軸・頂点とグラフ、最大値・最小値。KaTeX数式、成立条件、解説、途中式、基本例題、1問チェック、頂点を動かすグラフ。
- 検索：登録済み動画のタイトル、科目・単元・公式・用語・教材・例題。全半角と「二次／2次」などを正規化。
- 学習管理：学習状態と理解度を分離。復習登録、メモ、確認問題の選択、再生位置をIndexedDBに保存。JSON書き出し。
- PWAのマニフェストとアプリアイコン。プロダクションビルドはアプリ・教材をオフライン用に保存します。YouTubeの動画・サムネイルはService Workerで保存しません。

動画はサンプルの架空データではありません。公式IFrame Player APIの`getPlaylist()`で**1,022本の動画ID**を取得し、1,022本すべてのタイトル・投稿者・サムネイルを公式oEmbedで取得しました（失敗0件）。既存の代表動画のうち重複しない2本も維持し、アプリ内の登録動画は計1,024本です。公開日時・説明文・動画時間・API上の埋め込み可否は未取得です。今回の収録範囲は公式サイトの45単元です。公式サイト未掲載の動画を含めた網羅性は未確認です。全数学動画の総数は未確定です。

新着欄は「同期前」と表示します。二次関数以外の独自教材は準備中ですが、公式サイト掲載の高校33・中学12の単元から、登録した各授業をアプリ内で開けます。公式サイト未掲載の動画は今後の収録対象です。

## 保存と動画

学習記録は、この端末・ブラウザ・オリジンのIndexedDBに保存します。端末間の同期・アカウント・バックアップ復元は未実装です。再生完了で「理解できた」には変わりません。

動画ファイルを取得・ダウンロードする機能はありません。単元内の各動画をVideo IDで登録し、公式プレーヤーに動画IDを渡して個別再生します。公式の`controls=0`でYouTube標準の操作バーを非表示にし、映像の外側にMathveoの操作バーを配置します。速度変更はIFrame Player APIの対応速度から選び、実際の変更をAPIから確認して表示します。再生位置・音量・ミュートもAPIで操作し、全画面でもMathveoの操作バーを利用できます。

アプリ側のYouTubeへ移動するボタンは削除しました。投稿者・出典・分類は「動画の詳細」に折りたたみます。YouTubeのタイトル・ロゴ・広告・リンクを覆い隠したり、プレーヤーを切り抜いたりすることはしません。`showinfo`・`modestbranding`は廃止済みで、公式埋め込みを映像だけにする設定はありません。埋め込み不可・非公開・接続制限は回避しません。字幕設定の独自操作は未実装です。

各動画の学習済み・メモ・再生位置は既存のIndexedDB保存処理を使います。実映像再生と、実再生位置からの保存・再開の確認は別です。従来の二次関数3テーマの教材と学習機能は維持しています。


Mathveoは「超わかる！授業動画」やYouTubeの公認・提携アプリではありません。教材は独自の補助教材です。動画の書き起こし、動画内の問題を再現した教材、確認していない時刻へのリンクは掲載していません。対応は「関連教材」「推定候補・要確認」と表示します。

## 数学の検証

`npm run check` は型、KaTeX、分類、検索、YouTube収集機構のページング・重複排除・失敗・鮮度制御を検証します。APIのテストはモックです。実際に全動画を取得した証明ではありません。

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install sympy==1.14.0
python scripts/verify-math.py
```

独立したSymPy検証と成立条件の確認を行った3テーマを掲載しています。教材の数式・例題を変更した場合は、検証スクリプトも内容に合わせて見直してください。

## 単元の動画を更新する

`catalog-import.html`は保守用の収録ページです。公式IFrame Player APIの`getPlaylist()`で得た動画IDを、表示されたJSONから保存します。動画本体やYouTubeのwatchページは取得しません。

```bash
python scripts/import-player-inventory.py inventory.json --workers 12
```

公式oEmbedでメタデータを取得し、`src/data/registered-videos.json`を生成します。タイトル等が取得できないIDは「タイトル未取得」として区別し、失敗理由を保存します。`docs/video-inventory-20261012.json`に今回のID取得結果、`docs/oembed-metadata-20261012.json`に確認できたメタデータを記録します。Data API v3のライブ取得とは別の取得経路です。
