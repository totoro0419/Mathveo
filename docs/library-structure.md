## 情報構造

数学ライブラリ → 学校段階 → 科目 → 単元 → 公式の授業順で並ぶ個別動画。ホームは実際の履歴、科目選択、最近の学習、復習、独自教材へのアクセスで構成します。初回には科目選択へ案内し、試作動画や教材の存在を推薦理由にしません。

公式サイト分類と現行課程分類を切り替えられます。旧数学Bのベクトル、旧数学Ⅲの複素数平面・式と曲線の参照先は従来どおり維持します。

独自教材は`Topic.unitIds`で公式単元に紐付けます。新しい教材をこの関係に追加すれば、単元と所属動画に関連教材として表示されます。教材がない単元には無効な教材タブやエラー表示を加えません。動画内容と同一の教材であるという断定はしません。動画との個別対応根拠は`VideoTopicLink`に残します。

## 検索

動画結果を先に表示します。表示タイトルの完全一致・前方一致・部分一致、元タイトル、所属単元、タイトルから確認された動画種別、科目、取得済み説明文の順に重みを付けます。すべての検索語が一致した結果が対象です。同点なら分類の確認状態、公式単元への所属、公式の単元・授業順、動画IDで順位を確定します。登録順は使いません。手動登録動画も、検索語と最も一致すれば先頭に出ます。

## 記録・進捗

IndexedDB名・バージョン・既存のキーを変更していません。`video:VideoID`と`topic:テーマID`の両方をホームと復習に表示します。動画を初めて開いた場合は学習中を記録します。既存の状態・理解度・メモ・再生位置は維持します。

科目・単元の進捗の分母は該当する固有動画ID数です。教材テーマの進捗は別に明記します。再生完了、学習済み、理解度も独立しています。学習状態フィルタを使っても、授業番号は公式の順序のままです。
