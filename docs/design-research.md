## Mathveoに採用した原則

以下は調査結果から選んだ**本アプリの設計判断**です。参考サービスの機能をそのまま実装したという意味ではありません。

1. ホームは「次に学ぶこと」が主役。大きな学習入口、科目の帯、二次関数の順序付きリストを設け、架空の学習時間や連続学習日数は表示しない。
2. 動画と独自教材を同じテーマで結ぶ。広い画面では横に並べ、スマートフォンでは動画の下に教材タブを置く。動画の再生完了と数学の理解度を分ける。
3. 内容を段階的に開く。公式→解説→例題→関連動画の順に配置。例題の解答を自分の意思で開き、1問チェックで答えと理由を確認する。
4. 表より学習向けのリストを使う。科目・単元・詳細テーマの位置が分かるように、パンくずと共通ナビゲーションを維持する。
5. 小さな操作にも結果を返す。保存中／保存済み／保存失敗、復習の登録状態、確認問題の採点、コピー結果を表示する。

## ブランドとトークン

独自のMathveoアイコンは、学びを表すMと再生の方向を組み合わせたSVGです。第三者のロゴをアプリのブランドには使用していません。

| 用途         | 値・判断                                                                  |
| ------------ | ------------------------------------------------------------------------- |
| 主色         | `#2563EB` コバルトブルー                                                  |
| 本文・見出し | `#14274A` ネイビー                                                        |
| 補助色       | `#38BDF8`、淡い青の面、控えめな緑の学習済み表示                           |
| 背景・面     | `#F8FAFF`、白、`#E8F1FF`                                                  |
| 書体         | ローカル配信のInter Variable＋日本語OS書体。数式はKaTeXのローカルフォント |
| 余白         | 4pxを基本に、8・12・16・20・24・28・32pxを中心に設計                      |
| 角丸         | ボタン8–10px、教材11–14px、メインの学習入口18px前後                       |
| 情報量       | 広い画面は2ペイン。スマートフォンは1列＋4項目の下部ナビ                   |
| 動き         | 150–180msの色・影の変化。`prefers-reduced-motion`に対応                   |

## アクセシビリティと端末ごとの設計

ネイティブのリンク、ボタン、select、textarea、radio、detailsを使用。タブには選択状態・パネルの関連付け・左右キー操作を実装しました。フォーカスの輪郭、本文へ移動、見出しへのフォーカス移動、数式のMathML、コピー用LaTeXを用意しています。

スマートフォンはサイドバーを下部ナビに置き換えます。科目の横スクロールと教材タブの局所スクロールは、ページ全体の横スクロールと分けています。本文と公式の説明は約14px以上、主な操作は44px以上の高さに調整しました。PC・タブレットでは必要な余白と読み幅を確保します。
